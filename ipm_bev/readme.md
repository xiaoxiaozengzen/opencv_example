# Overview

对于理想针孔相机：地面BEV平面和原图之间符合单应关系，一个3x3的矩阵搞定

对于鱼眼：鱼眼的畸变是强非线性的，比如实际是直线，但是畸变后显示曲线。所以其转换BEV平面不能直接使用单应

对于鱼眼理论上可以按照这个流程：

* 鱼眼图像 -> 去畸变 -> 虚拟针孔 -> 透视变换H -> BEV
* 但是有个问题，就是鱼眼会把边缘拉的很厉害，实际生产中一般不这样做。并且针孔无法还原大于90°的场景，然后BEV图像最需要的就是车身周围几米的地面视角，会丢视场

对于鱼眼相机实际生产中：

* 跳过中间图像，直接做逐像素的复合映射，对BEV中的每个像素直接算出原始鱼眼图的浮点源坐标，并进行插值
* BEV像素(c,r) -> 地面点 P(X,Y,0) -> 相机坐标系 p = R * P + t -> 归一化平面(x,y)=(X_c/Z_c, Y_c/Z_c) -> 加畸变 -> 鱼眼原图坐标(u,v)
